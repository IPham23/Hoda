# Hodarizk

Responsive fashion and runway model website migrated from WordPress (Elementor Pro) to a fully coded React and TypeScript application.

Tech Stack:
- React
- TypeScript
- Tailwind CSS
- WordPress (original CMS)
- Adobe XD

Overview:
The website was initially built using WordPress and Elementor Pro. It was later rebuilt using React to improve flexibility, performance, and long-term scalability.

Highlights:
- Fully component-based layout
- Clean TypeScript structure
- Optimized loading performance
- Responsive design across devices

My Role:
- Rebuilt UI in React
- Converted design from Adobe XD into reusable components
- Implemented responsive styling with Tailwind

How to run locally:
1. npm install
2. npm run dev
